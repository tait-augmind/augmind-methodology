# 16 — Lane B: Seller & Referral Relationships (synthetic)

**Lane owner:** Partner + AI/Process Lead.

## Stage 01
- 1.1 Map how listings arrive: broker, attorney, direct seller, repeat client.
- 1.2 Source segmentation by conversion speed and retention. Benchmark: referred prospects convert ~4× faster; 37% higher retention; 55–70% cheaper than paid.
- 1.3 Future-state referral engine: prompt → ask → follow-up → nurture.
- 1.4 Gaps: no CRM evidence, aging rainmakers, no post-auction ask. Gate G1.

## Stage 02
- 2.1 Referral engine: 48-hour NPS + structured testimonial request; attorney lunch-and-learns.
- 2.2 Nurture cadence by source type.
- 2.3 Measurement lock: referrals → signed listings; time-to-contract. Gate G2.

## Stage 03
- 3.1 CRM source/contact/status for every listing.
- 3.2 Automated sequences: post-auction ask, quarterly attorney touch, broker nurture.
- 3.3 Referral dashboard. Gate G3.

## Stages 04–05
Value realization vs 4× conversion benchmark; runbook; retainer; trend by source mix; external quality sign-off.
