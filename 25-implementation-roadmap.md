# 25 — Implementation Roadmap (12 weeks, gated)

## Phase 1 — Weeks 1–3 Foundation
CRM live. Zapier/Make connected. UTM taxonomy enforced. Intake form live.
No channel mix changes yet. Stop the data loss first.
Gate: client accepts CRM schema + UTM dictionary.

## Phase 2 — Weeks 4–6 Marketing automation
Templates live. Email layer on. Retargeting from CRM segments.
First measurable movement on views-to-downloads.
Gate: first-cycle measurement pack accepted.

## Phase 3 — Weeks 7–9 Paperwork automation
PandaDoc contracts. Auction-export parse. Plaid/feed reconciliation.
Re-keying dies here.
Gate: two weeks of ≥95% first-pass document accuracy.

## Phase 4 — Weeks 10–12 Optimize and hand off
Drips tuned. Channel mix refined against real source data. Runbook written. Retainer proposal on table.
Gate G4: client accepts run state before retainer billing starts.

## Rules
- Gate at each phase. Client accepts output or names gaps.
- No silent pivots. Change Control Note for metric, data, automation, and commercial impact.
- Auction platform is out of scope unless it fails a named handoff.
