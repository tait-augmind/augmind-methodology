# 07 — Stage 04 — Validate and Run

**Status:** Sourced draft — advisory only, client-agnostic.

## Decision
Can the client accept the result, and is it ready to run under AugMind?

## Work
- 4.1 Check against acceptance criteria — verify the deliverable meets the locked metric and the client's stated success definition.
- 4.2 Transfer ownership and access — hand over credentials, documentation, and operational responsibility.
- 4.3 Stand up the repeatable process — automation, monitoring, and the operating cadence that produces recurring revenue.

## Deliverable
D4.1: accepted deliverables plus a running process with named owners, support boundaries, and a recurring operating plan.

## Gate
G4: client accepts the run state or names specific gaps. Running starts only after acceptance.
